# 👑 منصة أبو ندم الرسمية VIP | Abu Nadam Official Hub

منصة ويب عصرية وفائقة الفخامة (Luxury Royal Dark & Gold) مخصصة لعرض وإدارة كافة القنوات، الحسابات الرسمية، روابط البث المباشر ومواقع التواصل الاجتماعي الخاصة بصانع المحتوى والستريمر **أبو ندم**.

---

## ✨ المميزات الرئيسية

### 👑 أولاً: تجربة المشاهد والزائر (Viewer & Guest Experience)
* **دخول سريع كزائر (Guest Mode):** تصفح فوري للقنوات والحسابات بنقرة زر واحدة دون الحاجة لتسجيل بيانات.
* **تسجيل دخول بالبريد الإلكتروني:** لحفظ التفضيلات الشخصية وتخصيص الاسم والأفاتار.
* **تصنيفات متعددة:** (قنوات الفيديو، البث المباشر، التواصل الاجتماعي، المجتمعات والجروبات، التواصل والخاص).
* **بحث فوري وفلترة سريعة:** العثور على أي قناة أو حساب فور كتابة أي حرف.
* **المفضلة الشخصية ⭐:** إمكانية تمييز القنوات المفضلة للوصول السريع إليها في أي وقت.
* **طرق عرض متعددة:** إمكانية التبديل بين العرض الشبكي (Grid View) وعرض القائمة (List View).
* **نسخ ومشاركة سريعة:** نسخ روابط القنوات بنقرة واحدة، ومشاركة المنصة مع باركود QR Code تفاعلي.

### ⚙️ ثانياً: لوحة تحكم المدير (Admin Dashboard - أبو ندم)
* **تسجيل دخول آمن للمدير:** محمي برمز سري Master PIN (الافتراضي: `1234`).
* **إدارة الحسابات والقنوات:**
  * إضافة حساب جديد مع تحديد المنصة، الرابط، الفئة، عدد المتابعين، الشارة، لون التوهج، وأيقونة FontAwesome.
  * تعديل أي حساب موجود أو حذفه بنقرة زر.
  * تثبيت الحسابات المهمة في المقدمة 📌 أو إخفاؤها/تعطيلها مؤقتاً 🟢/🔴.
* **تخصيص الملف التعريفي:**
  * تعديل الاسم، اللقب، النبذة، صورة البروفيل (Avatar)، صورة الغلاف (Banner)، والموقع الجغرافي.
  * إدارة شريط الإعلانات العاجلة المتحرك (تعديل النص وتشغيله/إيقافه).
  * تغيير الرمز السري للمدير (PIN).
* **لوحة الإحصائيات:** عداد الزيارات، عداد النقرات لكل قناة، وقائمة أكثر القنوات زيارة.
* **النسخ الاحتياطي السحابي:**
  * تصدير كافة البيانات في ملف `JSON` بنقرة واحدة لحفظها على جهازك.
  * استيراد البيانات من ملف `JSON` في أي وقت أو على أي جهاز جديد.

## 🚀 دليل رفع المنصة وتشغيلها على GitHub Pages مجاناً

المنصة مصممة بتقنيات الويب النقية (HTML5, Tailwind CSS, Vanilla JS) بحيث تعمل مباشرة على **GitHub Pages** بدون الحاجة لأي خادم أو تكاليف استضافة.

### الخطوة 1: إنشاء مستودع جديد على GitHub
1. ادخل إلى موقع [GitHub.com](https://github.com) وسجل دخولك.
2. اضغط على زر **New Repository** (+).
3. اكتب اسم المستودع (مثلاً: `abu-nadam-links`).
4. اختر نوع المستودع: **Public** ثم اضغط **Create repository**.

### الخطوة 2: رفع ملفات المشروع
افتح موجه الأوامر (PowerShell أو Git Bash) في مجلد المشروع ونفّذ الأوامر التالية:

```bash
git init
git add .
git commit -m "الإصدار الأول - منصة أبو ندم الفخمة VIP"
git branch -M main
git remote add origin https://github.com/USERNAME/abu-nadam-links.git
git push -u origin main
```
*(استبدل `USERNAME` باسم حسابك على GitHub)*

### الخطوة 3: تفعيل رابط GitHub Pages
1. ادخل على صفحة المستودع على GitHub.
2. اذهب إلى **Settings** (الإعدادات) > ثم من القائمة الجانبية اختر **Pages**.
3. تحت قسم **Build and deployment**:
   - Source: **Deploy from a branch**
   - Branch: اختر **main** والمجلد **/ (root)**
4. اضغط على **Save**.
5. بعد دقيقة واحدة، سيظهر لك الرابط الرسمي لموقعك:
   `https://USERNAME.github.io/abu-nadam-links/`
